## 2. 배포 순서

### A. Backend (EC2/Docker)
1. **코드 배포**: GitHub `main` 브랜치로 Push (자동 배포 트리거)
   ```bash
   git push origin main
   ```
2. **서비스 확인**: 배포 후 서비스가 정상적으로 올라왔는지 확인 (Health Check)

### B. Database Migration (Production)
**주의**: 이번 버전은 DB 테이블 구조 변경이 있습니다.
EC2 서버에 접속하여 다음 단계를 수행하세요.

1. **SQL 마이그레이션 적용** (컬럼 추가)
   ```bash
   # EC2 접속
   ssh -i ainative-key.pem ubuntu@ec2-host
   
   # Docker 컨테이너 접속
   docker exec -it backend /bin/bash
   
   # psql 등으로 SQL 실행 (또는 Python 스크립트 활용)
   # backend/migrations/20260105_add_description_to_templates.sql 내용 실행
   ```
   > **SQL**: `ALTER TABLE prompttemplate ADD COLUMN IF NOT EXISTS description TEXT;`

2. **데이터 마이그레이션 실행** (설명 채우기)
   서버 내에 포함된 스크립트를 실행합니다.
   ```bash
   # Docker 컨테이너 내부에서
   python backend/scripts/v3.5.0_update_descriptions.py
   ```
   *참고: 스크립트가 없다면, `git pull`이 제대로 되었는지 확인하거나 수동으로 파일을 복사해야 할 수 있습니다.*
