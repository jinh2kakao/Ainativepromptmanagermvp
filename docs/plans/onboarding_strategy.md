# Growth Strategy: Onboarding Flow Optimization

## 1. 개요 (Executive Summary)
**목표:** 신규 사용자의 이탈률(Bounce Rate) 감소 및 Activation Rate(가입 후 첫 핵심 행동 완료율) 30% 증가.
**전략:** "Show, Don't Tell". 복잡한 설정 없이 즉시 가치를 경험하게 하는 **Progressive Onboarding** 도입.
**Aha Moment 정의:** 사용자가 **"내 의도에 딱 맞는 고품질 프롬프트가 단 10초 만에 완성되는 경험"**을 했을 때.

## 1. 단계별 목표 설정 근거 및 원칙 (CoT 결과)

### 단계 1: 가치 제안 및 진입 (Landing Hook)
*   **목표:** 3초 안에 사용자의 호기심을 자극하여 '이탈'을 '탐색'으로 전환.
*   **근거/원칙:** **Benefit-Oriented Headline**. 기능(Feature)이 아닌 혜택(Benefit)을 강조해야 합니다. "프롬프트 관리 도구"가 아니라 "최고의 AI 답변을 얻는 방법"으로 접근합니다.
*   **UX 원칙:** **Minimalism**. 불필요한 내비게이션을 제거하고 오직 '시작'에만 집중시킵니다.

### 단계 2: 문맥 파악 (Contextualization)
*   **목표:** 사용자의 페르소나(개발자, 마케터 등)를 파악하여 개인화된 경험 제공 준비.
*   **근거/원칙:** **Relevance**. 사용자는 자신과 관련 없는 콘텐츠를 볼 때 이탈합니다. 직무/목적을 묻는 행위 자체가 "나를 위한 서비스"라는 인식을 심어줍니다.
*   **UX 원칙:** **Hick's Law**. 선택지를 최소화(3~4개)하여 의사결정 부하를 줄입니다.

### 단계 3: 매직 템플릿 경험 (Discovery)
*   **목표:** 사용자가 고민할 필요 없이 "이거면 되겠다" 싶은 고품질 템플릿을 발견하게 함.
*   **근거/원칙:** **Curiosity Gap**. "내가 직접 쓰는 것보다 훨씬 낫다"는 것을 시각적으로 증명해야 합니다. 빈 화면(Empty State)은 최악의 경험입니다.
*   **UX 원칙:** **Recognition over Recall**. 프롬프트를 창작하게 하지 말고, 좋은 예시를 선택하게 합니다.

### 단계 4: 즉시 최적화 (Active Engagement)
*   **목표:** 사용자가 직접 상호작용(Input)하여 결과물이 '자신의 것'임을 느끼게 함(Endowment Effect).
*   **근거/원칙:** **Interactive Value**. 단순히 보는 것보다 직접 조작했을 때 애착이 형성됩니다. AI 모델(GPT-4 등)을 선택하는 간단한 행위로 전문성을 부여합니다.
*   **UX 원칙:** **Feedback Loop**. 버튼 클릭 즉시 시각적 피드백(애니메이션)을 주어 대기 시간을 지루하지 않게 합니다.

### 단계 5: 가치 실현 및 저장 (The Aha Moment & Retention)
*   **목표:** 완성된 프롬프트를 확인하고 이를 소유(저장/복사)하기 위해 가입/로그인을 유도.
*   **근거/원칙:** **Reciprocity**. 먼저 가치(완성된 프롬프트)를 제공했으므로, 사용자는 저장하기 위해 기꺼이 가입할 것입니다.
*   **UX 원칙:** **Lazy Registration**. 가치는 먼저, 회원가입은 나중에.

## 2. 온보딩 플로우 설계

### 단계 1: [Hook] 가치 제안 입구
*   **플로우 차트:** 유입(Landing) → Hero Section(단일 버튼)
*   **화면 설명:**
    *   **헤드라인:** "AI가 내 마음을 읽은 것처럼. 완벽한 프롬프트를 10초 만에."
    *   **서브:** "복잡한 프롬프트 엔지니어링 없이, 전문가 수준의 답변을 얻으세요."
    *   **액션:** `[무료로 체험하기]` (클릭 시 별도 페이지 이동 없이 바로 단계, 모달/화면 전환)
    *   **Background:** 성공적인 AI 답변 사례가 흐릿하게 지나가는 애니메이션.

### 단계 2: [Context] 페르소나 설정
*   **플로우 차트:** 시작 버튼 클릭 → 직무 선택 오버레이
*   **화면 설명:**
    *   **질문:** "어떤 작업을 도와드릴까요?"
    *   **선택지 (카드형):**
        *   💻 **개발/코딩** (코드 리팩토링, 버그 수정)
        *   📝 **콘텐츠/마케팅** (블로그, 이메일, 광고 카피)
        *   💼 **기획/비즈니스** (기획안, 이메일, 요약)
        *   🎓 **학습/연구** (요약, 번역, 퀴즈)
    *   **액션:** 카드 클릭 즉시 다음 단계로 자동 진행 (별도 '다음' 버튼 없음).

### 단계 3: [Magic] 추천 템플릿 선택
*   **플로우 차트:** 직무 선택 → 해당 카테고리의 Best 템플릿 3종 노출
*   **화면 설명:**
    *   **헤드라인:** "{직무} 전문가들이 자주 쓰는 프롬프트입니다."
    *   **콘텐츠:** 선택한 직무의 Top 3 템플릿 카드.
        *   예: (개발 선택 시) "React 컴포넌트 생성기", "API 문서 자동화", "코드 리뷰어"
    *   **가이드:** "가장 마음에 드는 하나를 선택해보세요." (손가락 포인터 애니메이션이 1위를 가리킴)

### 단계 4: [Interaction] 초간단 커스텀 & 최적화
*   **플로우 차트:** 템플릿 선택 → 입력 폼(변수 1~2개) → [최적화] 버튼
*   **화면 설명:**
    *   **화면 분할:** 좌측(입력) / 우측(미리보기).
    *   **입력:** 복잡한 프롬프트 전체가 아니라, **핵심 변수**만 입력받음.
        *   예: "만들고 싶은 컴포넌트 이름은?" -> `[ 게시판 리스트 ]`
    *   **옵션:** "사용할 AI 모델" (GPT-4 / Claude 3.5 선택 칩).
    *   **액션:** `[프롬프트 생성하기 ✨]` 버튼. 클릭 시 화려한 파티클/로딩 애니메이션("AI가 최적화 중...") 2초 노출.

### 단계 5: [Activation] 결과 확인 및 저장 유도
*   **플로우 차트:** 생성 완료 → 결과(Markdown 뷰어) → [복사/저장] 버튼 → 로그인 모달
*   **화면 설명:**
    *   **결과 화면:** 사용자가 입력한 짧은 단어가 거대한 고품질 프롬프트로 변환된 것을 보여줌 (Before/After 비교 토글 제공).
    *   **핵심 강조:** "이 프롬프트로 얻을 수 있는 결과" 예시를 미리보기 이미지로 제공.
    *   **Call to Action:**
        *   `[클립보드 복사]` (비로그인 허용, Toast 메시지로 "복사되었습니다. 가입하고 더 많은 템플릿을 저장하세요!" 노출)
        *   `[내 라이브러리에 저장]` (클릭 시 소셜 로그인 모달 팝업).
