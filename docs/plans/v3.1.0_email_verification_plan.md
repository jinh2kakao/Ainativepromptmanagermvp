# 구현 계획서 - 이메일 인증 및 회원 등급 개편 (Enterprise 포함)

## 목표 (Goal Description)
1.  **이메일 인증**: SMTP 기반 인증 시스템 구축.
2.  **등급 정책 고도화**: Free(5회), Pro(40회), Enterprise(80회 + 팀 기능)로 정책 세분화.
3.  **UI 반영**: 업그레이드 모달에 Enterprise 옵션 추가.

## 제안된 변경 사항 (Proposed Changes)

### 백엔드 (Backend)

#### [NEW] [backend/routers/verification.py]
- 이메일 인증 라우터 (Send/Verify Code).

#### [MODIFY] [backend/core/config.py] (또는 constants 파일)
- 등급별 제한 횟수 상수 정의:
  ```python
  AI_LIMITS = {
      "FREE": 5,
      "PRO": 40,
      "enterprise": 80
  }
  ```

#### [MODIFY] [backend/routers/prompt_optimization.py] & [backend/routers/crucible.py]
- **사용량 체크**:
  1. `current_user.user_type` 확인.
  2. 오늘 사용량(`count`) 조회.
  3. `count >= AI_LIMITS[user_type]` 이면 403 에러 반환.

#### [MODIFY] [backend/routers/teams.py]
- **팀 생성 권한**:
  - `create_team` 함수 진입 시 `current_user.user_type == "enterprise"` 확인.
  - 아니면 403 Forbidden ("Enterprise Plan required") 반환.
