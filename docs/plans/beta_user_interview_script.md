# [베타 서비스 사용자 인터뷰 스크립트]

> **Note**: 이 스크립트는 정성적 리서치를 기반으로 하되, 응답의 경향성을 파악하기 위해 객관식 보기를 포함하고 있습니다. 인터뷰어는 참여자가 보기를 선택한 후, 그 이유를 구체적으로 설명하도록 유도해야 합니다.

## 1. 아이스브레이킹 (Icebreaking)
| No. | 질문 목적 (Purpose) | 인터뷰 질문 (Script) 및 보기 | 꼬리물기 질문 예시 (Probing) |
| :--- | :--- | :--- | :--- |
| 1-1 | 라포 형성 및 업무 맥락 파악 | **Q. 평소 업무나 일상에서 AI(ChatGPT, Claude 등)를 얼마나 자주 활용하시나요?**<br><br>*(보기)*<br>1. 매일 거의 모든 업무에 사용<br>2. 주 3-4회, 필요할 때마다 사용<br>3. 주 1-2회, 특별한 경우에만 사용<br>4. 거의 사용하지 않음<br>5. 관심은 있지만 사용법을 잘 모름 | "자주 사용하신다면, 가장 최근에 AI가 꼭 필요했던 구체적인 순간은 언제였나요?" |
| 1-2 | 기존 해결 방식 탐색 | **Q. AI에게 원하는 답변을 얻기 위해 프롬프트를 작성하실 때, 주로 어떻게 해결하시나요?**<br><br>*(보기)*<br>1. 그때그때 즉흥적으로 작성<br>2. 메모장/노션 등에 저장해둔 나만의 프롬프트 복사<br>3. 인터넷 커뮤니티나 블로그 검색 후 참고<br>4. 프롬프트 마켓이나 전문 사이트 이용<br>5. 주변 동료에게 물어보거나 공유받음 | "그 방식을 사용하시면서 가장 번거롭거나 아쉬웠던 점은 무엇이었나요?" |
| 1-3 | 인터뷰이 성향 파악 | **Q. 새로운 생산성 도구를 도입할 때 가장 중요하게 보는 요소는 무엇인가요? (1순위 선택)**<br><br>*(보기)*<br>1. **사용 편의성** (배우기 쉽고 직관적인가)<br>2. **기능의 강력함** (내가 원하는 디테일한 설정이 가능한가)<br>3. **가격** (무료 혹은 합리적인 비용인가)<br>4. **호환성** (기존 업무 툴과 잘 연동되는가)<br>5. **디자인** (세련되고 보기 좋은가) | "과거에 이 기준을 충족하지 못해서 사용을 중단했던 서비스가 있다면 무엇인가요?" |

## 2. 도입 (Introduction)
| No. | 질문 목적 (Purpose) | 인터뷰 질문 (Script) 및 보기 | 꼬리물기 질문 예시 (Probing) |
| :--- | :--- | :--- | :--- |
| 2-1 | 유입 경로 및 첫인상 | **Q. 이번 베타 서비스에 관심을 갖게 된 가장 결정적인 문구(Key Hook)는 무엇이었나요?**<br><br>*(보기)*<br>1. "내 직무에 딱 맞는 템플릿 추천"<br>2. "전문가가 만든 고퀄리티 프롬프트"<br>3. "복잡한 프롬프트 관리의 자동화"<br>4. "무료 체험 가능"<br>5. 기타 (직접 입력) | "그 문구가 왜 본인의 상황에서 매력적으로 느껴지셨나요? 당시 어떤 문제를 해결하고 싶으셨나요?" |
| 2-2 | 온보딩 경험 (Guest) | **Q. 로그인 없이 체험한 '직무 선택'과 '템플릿 추천' 과정은 어떠셨나요?**<br><br>*(보기)*<br>1. 매우 만족 (추천이 정확하고 과정이 매끄러움)<br>2. 만족 (내 직무에 맞는 템플릿을 찾음)<br>3. 보통 (나쁘지 않으나 특별하지 않음)<br>4. 불만족 (내 직무가 없거나 추천이 엉뚱함)<br>5. 매우 불만족 (과정이 복잡하고 이해하기 어려움) | "(만족/불만족 선택 시) 구체적으로 어떤 화면이나 단계에서 그런 느낌을 받으셨나요?" |
| 2-3 | 아하 모먼트 검증 | **Q. 서비스를 사용하면서 '이거 괜찮다(Aha Moment)'라고 느꼈던 순간은 언제였나요?**<br><br>*(보기)*<br>1. 직무를 선택하자마자 관련 템플릿이 뜰 때<br>2. 템플릿을 선택하고 내용을 입력했을 때<br>3. AI가 생성한 최종 프롬프트 결과를 봤을 때<br>4. 생성 결과를 복사해서 바로 써봤을 때<br>5. 특별히 인상 깊은 순간이 없었음 | "그 경험이 회원가입을 결심하는 데 얼마나 영향을 주었나요?" |
| 2-4 | 가입 장벽 탐색 | **Q. (가입자 대상) 가입을 하게 된 가장 큰 동기는 무엇인가요? / (미가입자 대상) 가입을 망설인 이유는?**<br><br>*(보기)*<br>1. 결과물을 저장하고 계속 쓰고 싶어서 / 저장할만큼 가치있지 않아서<br>2. 더 많은 기능을 써보고 싶어서 / 기능이 충분하지 않아서<br>3. 무료라서 부담 없이 / 유료 전환될까봐 걱정돼서<br>4. 가입 절차가 간편해서 (구글 로그인 등) / 가입 절차가 귀찮아서<br>5. 호기심에 / 개인정보 입력이 우려돼서 | "가입 과정에서 만약 이 기능이나 혜택이 있었다면 더 망설임 없이 가입했을 것 같나요?" |

## 3. 본론 (Main Body)
| No. | 질문 목적 (Purpose) | 인터뷰 질문 (Script) 및 보기 | 꼬리물기 질문 예시 (Probing) |
| :--- | :--- | :--- | :--- |
| 3-1 | 핵심 과업 수행 경험 | **Q. 사용해보신 기능 중 업무에 가장 실질적으로 도움이 된 것은 무엇인가요?**<br><br>*(보기)*<br>1. 직무별 추천 템플릿 탐색<br>2. 템플릿 변수 입력 및 커스터마이징<br>3. AI 프롬프트 최적화/수정 기능<br>4. 프롬프트 저장 및 관리 (라이브러리)<br>5. 도움이 된 기능이 없음 | "그 기능을 사용하면서 기존 업무 방식 대비 시간이 얼마나 단축되었나요? 혹은 퀄리티가 얼마나 좋아졌나요?" |
| 3-2 | 프롬프트 최적화 경험 | **Q. AI가 프롬프트를 자동으로 수정해주는 기능의 결과물 퀄리티는 어땠나요?**<br><br>*(보기)*<br>1. 기대 이상 (내가 쓴 것보다 훨씬 낫다)<br>2. 만족 (이 정도면 바로 쓸 수 있다)<br>3. 보통 (약간의 수정이 필요하다)<br>4. 아쉬움 (내 의도를 잘 반영하지 못함)<br>5. 사용해보지 않음 | "만약 결과물이 마음에 들지 않았다면, 어떤 부분이 가장 부족했다고 느끼셨나요?" |
| 3-3 | UI/UX 직관성 평가 | **Q. 원하는 템플릿을 찾거나 기능을 사용하는 데 있어 불편함을 느낀 적이 있나요?**<br><br>*(보기)*<br>1. 전혀 없음 (매우 직관적)<br>2. 거의 없음 (금방 적응함)<br>3. 가끔 있음 (찾는 메뉴가 눈에 잘 안 띔)<br>4. 자주 있음 (어디를 눌러야 할지 헷갈림)<br>5. 매우 많음 (사용을 포기하고 싶을 정도) | "구체적으로 어떤 화면에서 멈칫하거나 헤매게 되셨나요?" |
| 3-4 | Pain Point 발굴 | **Q. 서비스 이용 중 가장 아쉬웠던 점(Friction) 하나를 꼽는다면?**<br><br>*(보기)*<br>1. 템플릿 종류 부족<br>2. 생성 속도가 느림<br>3. 모바일에서의 사용성 불편<br>4. 저장/불러오기 기능의 복잡함<br>5. 설명 부족으로 인한 이해 어려움 | "그 불편함이 개선되지 않는다면 서비스를 계속 사용하실 의향이 있으신가요?" |
| 3-5 | 공유 및 협업 니즈 | **Q. 작성한 프롬프트를 다른 사람과 공유하고 싶다는 생각이 드셨나요?**<br><br>*(보기)*<br>1. 매우 그렇다 (팀원과 공유 필수)<br>2. 가끔 그렇다 (좋은 건 공유하고 싶음)<br>3. 별로 없다 (혼자 쓰는 게 편함)<br>4. 전혀 없다 (나만의 노하우로 간직하고 싶음)<br>5. 오히려 보안 때문에 공유 기능을 원치 않음 | "공유를 한다면 어떤 방식(링크 공유, 팀 워크스페이스 등)을 가장 선호하시나요?" |

## 4. 마무리 (Conclusion)
| No. | 질문 목적 (Purpose) | 인터뷰 질문 (Script) 및 보기 | 꼬리물기 질문 예시 (Probing) |
| :--- | :--- | :--- | :--- |
| 4-1 | Magic Wand (이상적 경험) | **Q. 이 서비스에서 딱 한 가지만 개선할 수 있다면, 무엇을 바꾸고 싶으신가요?**<br><br>*(보기)*<br>1. 더 다양하고 전문적인 템플릿 추가<br>2. 웹/앱 디자인 및 UI 개선<br>3. 더 빠르고 똑똑한 AI 모델 적용<br>4. 팀 협업 기능 추가<br>5. 커뮤니티 기능 활성화 | "그 부분이 개선된다면, 사용자님의 업무 효율이 어떻게 달라질까요?" |
| 4-2 | NPS (추천 의향) | **Q. 이 서비스를 동료나 지인에게 추천할 의향이 있으신가요? (10점 만점)**<br><br>*(보기)*<br>1. 강력 추천 (9-10점)<br>2. 추천함 (7-8점)<br>3. 보통 (5-6점)<br>4. 글쎄요 (3-4점)<br>5. 비추천 (0-2점) | "그 점수를 주신 가장 큰 이유는 무엇인가요?" |
| 4-3 | Willingness to Pay | **Q. 만약 이 서비스가 유료화된다면, 지불 의향이 있는 핵심 가치는 무엇인가요?**<br><br>*(보기)*<br>1. 무제한 프롬프트 생성 및 고성능 AI 모델<br>2. 검증된 전문가 템플릿 열람 권한<br>3. 팀 협업 및 관리 기능<br>4. 광고 제거 및 쾌적한 환경<br>5. 유료로는 사용할 의향이 없음 | "어느 정도의 월 이용료라면 합리적이라고 생각하시나요?" |
| 4-4 | 종료 및 감사 | **Q. 마지막으로 서비스 팀에게 꼭 전하고 싶은 말씀이 있으신가요?**<br><br>*(보기)*<br>1. 기능 제안<br>2. 버그 제보<br>3. 칭찬 및 격려<br>4. 기타 의견<br>5. 없음 | "소중한 의견 감사합니다. 향후 업데이트 시 반영하도록 노력하겠습니다." |
