# Implementation Plans

이 디렉토리는 프로젝트의 주요 기능 개발 및 변경사항에 대한 구현 계획(Implementation Plan) 문서를 포함합니다.

## 파일 명명 규칙

파일명 형식: `YYYY-MM-DD_설명.md`

예: `2025-12-08_template_system_design.md`

## 문서 목적

각 Implementation Plan은 다음 정보를 포함합니다:
- **목표 설명**: 해결할 문제 및 배경 컨텍스트
- **사용자 검토 필요사항**: 중요한 설계 결정, Breaking Changes 등
- **제안된 변경사항**: 컴포넌트별 구현 계획
- **검증 계획**: 자동화 테스트 및 수동 검증 방법

## 워크플로우

1. **Planning 단계**: AI가 implementation_plan.md 작성
2. **Review**: 사용자가 계획 검토 및 승인
3. **Execution**: 승인된 계획에 따라 구현
4. **Archiving**: 작업 완료 후 이 디렉토리에 저장

## 언어

모든 Implementation Plan은 **한글(Korean)**로 작성됩니다.
