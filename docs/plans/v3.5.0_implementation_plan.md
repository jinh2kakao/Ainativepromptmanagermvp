# Implementation Plan - v3.5.0 Dashboard & View Integration

## Goal Description
Implement two key user experience improvements:
1.  **Unified Prompt View Toggle:** Allow users to switch between List and Kanban views for their prompts, persisting the preference.
2.  **Dashboard Template Discovery:** Revamp the initial dashboard to show "Recent Templates" (for members) and "Popular Templates" (for all), responding to the issue of an empty initial state.

## User Review Required
> [!IMPORTANT]
> **Database Migration:** A new table `template_usage` will be created.
> **Layout Change:** The main dashboard (`/`) will be significantly altered. The existing "My Prompts" list will be moved below the new Template sections.
