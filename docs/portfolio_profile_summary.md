# Portfolio Profile Summary

## Technical Product Manager / Technical Product Owner

**"Engineering-Driven Decision Maker"**

B2C 커머스 및 여행 플랫폼 분야에서 18년간 비즈니스 로직과 기술 구현을 연결해온 **Technical Product Owner**입니다.
단순한 요구사항 정의를 넘어, **SQL 기반의 데이터 분석**과 **API 설계** 역량을 바탕으로 엔지니어링 팀과 동일한 언어로 소통하며 최적의 아키텍처를 함께 고민합니다.

최근에는 **기획부터 MVP 출시까지, ‘0 to 1’ 프로덕트 빌딩(Product Building)**을 리딩하며, 기획자가 직접 프로덕션 레벨의 워크플로우를 설계하고 구현하는 **Technical Product Management**의 새로운 지평을 열어가고 있습니다. 기획과 구현의 경계를 허물며 제품의 Time-to-Market을 극대화하는 것이 저의 핵심 역량입니다.
