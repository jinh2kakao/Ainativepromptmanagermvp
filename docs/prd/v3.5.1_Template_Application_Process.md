# PRD: 프롬프트 템플릿 적용 프로세스 개편 (v3.5.1)

## 1. 개요 (Overview)
*   **문서 버전**: v3.5.1
*   **작성일**: 2026-01-05
*   **목적**: 프롬프트 작성 시 템플릿 활용성을 높이기 위해 자동 적용 방식을 수동 조회 및 적용 방식으로 변경하고, 템플릿 탐색 효율성을 개선합니다.

## 2. 배경 및 문제점 (Context)
*   기존에는 직무 분류 선택 시 템플릿이 자동으로 강제 적용되어, 사용자가 작성하던 내용이 덮어씌워지거나 원치 않는 템플릿이 적용되는 불편함이 있었습니다.
*   우측 "미리보기" 영역은 작성 중에는 효용성이 낮아 공간 효율이 떨어집니다.
*   템플릿 상세 페이지에서 어시스턴스 모드(JSON 구조)의 템플릿이 문자열 그대로 노출되어 가독성이 떨어집니다.

## 3. 주요 요구사항 (Requirements)

### 3.1. 프롬프트 작성 페이지 (템플릿 조회 및 적용)
1.  **레이아웃 변경**
    *   우측 "미리보기(Preview)" 영역을 제거합니다.
    *   해당 영역을 **"템플릿 조회(Template Attributes/Lookup)"** 영역으로 변경합니다.
2.  **템플릿 자동 적용 로직 삭제**
    *   직무 분류(Category) 선택 시 템플릿이 에디터에 자동으로 적용(Auto-fill)되는 기능을 삭제합니다.
3.  **템플릿 조회 필터링**
    *   **직무 분류 연동**: 좌측 에디터 설정에서 직무 분류를 선택하면, 우측 템플릿 조회 영역에 해당 직무(및 소분류)에 해당하는 템플릿만 필터링하여 보여줍니다.
    *   **작성 모드 연동**: 현재 선택된 작성 모드(일반/어시스턴스)에 맞는 템플릿만 필터링합니다.
    *   **전체 노출**: 직무 분류가 선택되지 않은 경우, 전체 템플릿을 노출합니다.
4.  **검색 기능**
    *   템플릿 조회 영역 상단에 **키워드 검색(Search Input)** UI를 제공하여 템플릿을 빠르게 찾을 수 있도록 합니다.
5.  **템플릿 적용 (Action)**
    *   조회된 템플릿 리스트에서 항목을 클릭(또는 적용 버튼 클릭) 시, 해당 템플릿의 내용을 프롬프트 작성 영역에 적용합니다.
6.  **실행 취소 (Undo)**
    *   템플릿 적용으로 인해 기존 내용이 변경된 경우, 이를 **이전 상태로 되돌릴 수 있는 기능**을 제공합니다. (예: Toast 메시지의 Undo 버튼 등)

### 3.2. 템플릿 상세 페이지 (View)
1.  **모드별 뷰 구분**
    *   템플릿의 모드(일반/어시스턴스)에 따라 상세 내용을 다르게 표시해야 합니다.
2.  **어시스턴스 모드 시각화**
    *   어시스턴스 모드 템플릿의 경우, Content가 JSON 문자열로 저장되어 있습니다.
    *   이를 파싱하여 **구조화된 뷰(Role, Task, Context 등)**로 사용자에게 보여주어야 합니다. (Raw JSON 노출 지양)

## 4. 디자인/UI 가이드
*   **우측 사이드바**: 기존 Sticky Preview와 유사한 높이와 스타일을 유지하되, 내부에 리스트 뷰 및 검색창을 검색창을 배치합니다.
*   **템플릿 카드**: 좁은 사이드바 공간을 고려하여 컴팩트한 카드 디자인을 적용합니다 (제목, 간단한 설명, 태그 정도 노출).
*   **모바일 대응**: 모바일 뷰에서는 사이드바가 하단으로 이동하거나 숨김 처리될 수 있도록 반응형을 고려합니다 (기존 구조 따름).

## 5. 제외 사항 (Non-Requirements)
*   템플릿 생성/수정 기능에 대한 변경은 이번 범위에 포함되지 않습니다.
*   백엔드 API 변경은 최소화하며, 기존 API를 활용합니다.
