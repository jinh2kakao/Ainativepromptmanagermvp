## 1. 개요 (Overview)

### 1.1 배경 및 목적
초기 이탈률을 줄이고 사용자가 서비스의 핵심 가치(Aha Moment)를 빠르게 경험할 수 있도록 **Progressive Onboarding**을 도입합니다.
사용자가 로그인/가입 장벽 없이 고품질 프롬프트를 생성(체험)하게 함으로써, 자연스럽게 서비스의 유용성을 입증하고 가입을 유도합니다.

### 1.2 핵심 목표 (Key Metrics)
-   **Activation Rate:** 신규 방문자의 30%가 첫 프롬프트 생성을 완료.
-   **Sign-up Conversion:** 온보딩 완료 사용자의 50%가 회원가입 전환.
-   **Time to Value (TTV):** 유입 후 핵심 가치 경험까지 90초 이내 달성.

## 2. 사용자 시나리오 (User Stories)

### 2.1 Guest User
> "나는 이 서비스가 뭐하는 곳인지 모르지만, 내 업무에 도움이 된다면 써보고 싶다."
-   방문자는 회원가입 없이 바로 "나의 직무"를 선택하고 추천 템플릿을 볼 수 있어야 한다.
-   방문자는 템플릿을 선택하고 간단한 변수 입력만으로 완성된 프롬프트를 확인할 수 있어야 한다.
-   결과물을 복사하려 할 때, 가입하면 저장할 수 있다는 안내를 받아야 한다.

## 3. 기능 요구사항 (Functional Specifications)

### 3.1 Step 1: Landing Hook (가치 제안)
-   **URL:** `/onboarding/welcome` (신규 방문자 리다이렉트)
-   **UI:** 미니멀한 히어로 섹션. 배경에 성공 사례 애니메이션 재생.
-   **Action:** `[무료로 체험하기]` 버튼 하나만 존재. 클릭 시 즉시 Step 2로 이동.

### 3.2 Step 2: Persona Selection (직무 선택)
-   **URL:** `/onboarding/persona`
-   **Features:**
    -   4가지 핵심 직무 카드 제공 (개발, 마케팅, 기획, 학습).
    -   카드 클릭 시 선택 상태 저장(`localStorage` 활용) 및 Step 3 자동 이동.
    -   이탈 방지를 위해 '뒤로가기' 대신 '닫기' 버튼(홈으로 이동) 제공.

### 3.3 Step 3: Magic Template Discovery (템플릿 추천)
-   **URL:** `/onboarding/magic`
-   **Features:**
    -   Step 2에서 선택한 카테고리의 Top 3 템플릿 노출.
    -   각 템플릿은 "이름", "설명", "사용 횟수(Social Proof)" 표시.
    -   손가락 포인터 애니메이션으로 1위 템플릿 추천 강조.

### 3.4 Step 4: Instant Customization (최적화 체험)
-   **URL:** `/onboarding/magic` (Step 3와 동일 페이지 내 모달 또는 슬라이드 전환)
-   **Features:**
    -   선택한 템플릿의 핵심 변수(1~2개)만 입력받는 간소화된 폼.
    -   "AI 모델 선택" 칩 (GPT-4 / Claude 3.5).
    -   `[프롬프트 생성하기]` 버튼 클릭 시 화려한 로딩/생성 애니메이션(2~3초) 연출.

### 3.5 Step 5: Activation & Conversion (결과 및 가입)
-   **URL:** `/onboarding/result`
-   **Features:**
    -   생성된 전체 프롬프트 표시 (Markdown 뷰어).
    -   **Before/After 토글:** 입력한 단어 vs 완성된 프롬프트 비교.
    -   **Action 1 (Copy):** `[클립보드 복사]` -> 성공 Toast + "가입하고 저장하세요!" 메시지.
    -   **Action 2 (Save):** `[내 라이브러리에 저장]` -> 로그인/가입 모달 호출.

## 4. 데이터 모델 & API 요구사항

### 4.1 Onboarding Templates
-   `GET /api/onboarding/templates?category={category}`
-   관리자가 미리 선정한 카테고리별 High-Quality 템플릿 반환.

### 4.2 Guest Tracking (Optional but Recommended)
-   온보딩 이탈 지점을 파악하기 위한 간단한 로깅 (`POST /api/onboarding/track`).

## 5. 관리자 기능 요구사항 (Admin Requirements)

### 5.1 직무 분야(Category) 관리
-   **URL:** `/admin/categories`
-   **Data Spec:**
    -   `id` (UUID): 고유 식별자
    -   `order` (Int): 정렬 순서
    -   `name` (String): 직무 분야명 (예: 마케팅)
    -   `icon` (String): 직무 분야 아이콘 (Lucide Icon Name or URL) [New]
    -   `description` (String): 직무 분야 설명 [New]
    -   `templates` (List): 연결된 템플릿 목록 (Read-only view with Linker)

### 5.2 템플릿 연결 (Template Linking)
-   **Action:** 카테고리 상세/수정 모달에서 '연결된 템플릿' 관리.
-   **UI:**
    -   현재 연결된 템플릿 리스트 표시 (삭제 버튼 포함).
    -   `[템플릿 추가]` 버튼 클릭 시 템플릿 검색 팝업 호출.
    -   검색 팝업에서 템플릿 선택 시 해당 템플릿의 `category_id`를 현재 카테고리로 업데이트.
-   **Validation:** 하나의 템플릿은 하나의 카테고리에만 속함 (1:N 관계 유지).

## 6. UI/UX 가이드라인
-   **Focus Mode:** 온보딩 중에는 GNB/Footer를 숨겨 사용자가 오직 프로세스에만 집중하게 함.
-   **Micro-interaction:** 클릭, 선택, 생성 시 즉각적인 피드백(햅틱, 사운드, 비주얼) 제공.
-   **Speed:** 모든 단계 간 전환은 0.3초 이내로 즉시 이루어져야 함 (Client-side Transition).
