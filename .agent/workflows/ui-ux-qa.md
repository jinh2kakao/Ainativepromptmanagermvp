This workflow verifies the UI/UX of the frontend using Antigravity's Native Browser Control.

> [!IMPORTANT]
> **Language Rule**: All QA reports and summaries generated by this workflow MUST be written in **Korean** (Hangul).

# Prerequisites
- The workflow configuration must exist at `.antigravity/workflows/ui-ux-qa.yaml`.
- The frontend must be deployable to a preview environment.

# Steps to Execute

1. **Automatic Trigger**:
   - The workflow is configured to run automatically whenever a **Preview Environment** becomes `ready`.
   - Simply push your changes to a pull request or branch that generates a preview.

2. **Manual Verification**:
   - Check the `.antigravity/workflows/ui-ux-qa.yaml` file to ensure the test steps (viewports, selectors) are correct.
   - Captured screenshots and reports will be available in `.antigravity/artifacts/qa-reports/`.

3. ** troubleshooting**:
   - If the test fails, check if the `id="main-content"` exists in `ClientLayout.tsx`.
